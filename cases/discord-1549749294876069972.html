Hi everyone! I'm Paulo R. Lima from Brazil. I'm building Arandu, an open-source full-stack framework written in Go for building SaaS, APIs, and digital products. Arandu has grown into a fairly large ecosystem with typed UI components, real-time communication, infrastructure abstractions, CLI tooling, security rules, MCP integrations, and AI-assisted development workflows. I'm particularly interested in trying Jev as a decision layer inside our development tooling — especially for code analysis, validation, architectural decisions, and agent workflows where using a full LLM for every decision can be unnecessarily expensive and slow. I'd also like to experiment with Jev alongside our MCP and agent tooling to see where a fast decision model can replace or complement traditional LLM calls.
