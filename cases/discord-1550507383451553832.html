Hey everyone! first day of experimenting w/ Jev - I built a small open-source project called Reaper: https://github.com/Eliran-Turgeman/repear It’s a semantic linter for coding agents. I currently add a short instruction to my  AGENTS.md , which asks the agent to run Reaper after its normal tests and linters. You can see the exact workflow here: https://github.com/Eliran-Turgeman/repear/blob/main/AGENTS.md It’s still an early experiment, and I’m sure there’s plenty to improve especially around the rules, thresholds, and evaluations. Feedback is welcomed.
