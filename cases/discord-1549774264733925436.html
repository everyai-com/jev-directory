Hey everyone, built a lightweight, distraction-free Pomodoro web app called **focus-flow**. Most focus timers I tried had cluttered UIs or unnecessary bloat, so I put together something minimal for my own workflow. **Features:** * Configurable session cycles (Focus, Short & Long breaks, rounds tracking) * Fullscreen mode to kill tab distractions * Built-in ambient audio (rain, background noise) * Clean, modular ES modules structure under the hood **Repo:** https://github.com/w3ziqv/focus-flow Still fine-tuning the UX and code structure. Would appreciate any feedback on the implementation or ideas for features worth adding!
