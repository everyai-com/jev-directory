I'm building Solenoid, which is a, well, type-safe node-graph alternative to Excel. numbers/strings/dates/booleans all have different socket types so they can't be confused for one another. Supports all Excel functions (except the ones that are strictly for spreadsheet grids). The windows desktop build uses Rust/Polars for big operations but otherwise it runs in your browser. Has additional convenience functions + widgets + Obsidian integration. http://solenoid-ngc.vercel.app
