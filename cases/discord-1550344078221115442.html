I've been experimenting with Jev and loving it! I released two packages to work with it: - Jev MCP wraps Jev's decision making process into an MCP that you can give your regular LLM agents to work with https://github.com/jkudish/jev-mcp - Jev Browser uses Jev to control a chromium browser with playwright resulting in a really fast and cheap browser use agent https://github.com/jkudish/jev-browser
