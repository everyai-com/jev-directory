Privacy Policy

The Jev Directory is a public reference site — 50 runnable evals, 1,300+ community builds, and an MCP endpoint that serves them. There are no accounts, no analytics scripts, no advertising trackers, and no cookies set by us. What you search for is your business.

What we collect

Almost nothing. Browsing the directory, reading the capability pack, and calling the MCP endpoint work without signing in or identifying yourself, and we store none of your queries.

What our hosting provider logs

Like nearly every site, our host (Cloudflare Pages) keeps standard server logs for security and operations — typically your IP address, user agent, the page or endpoint requested, and the time. We do not combine these logs with anything else, and we do not sell or share them. They exist so the site stays up and abuse can be stopped.

Things that stay in your browser

Any preferences you set on the site itself — for example a development API override for the on-page chat widget — are kept in your browser's local storage on your device. They are never sent to us.

MCP and agent use

When an AI agent queries the MCP endpoint (/mcp), the request necessarily contains the question being asked — that is how the directory finds the matching eval or build. We process it to answer and keep no record of it. Running Jev itself happens between you and the Vercel AI Gateway under your own API key; those calls never pass through us.

Third parties

The directory links out to community projects, source posts, TypeSafe AI, and Vercel. Once you follow a link, that site's privacy policy applies, not this one.

Children

The directory is a technical reference for developers and is not directed at children under 13. We knowingly collect no data from anyone, including children.

Changes

If this policy changes, the updated version will be posted here with a new last-updated date. Material changes will also be noted in the public repository.

Contact

Questions about this policy? Open an issue at github.com/everyai-com/jev-directory/issues and the maintainers will respond.
