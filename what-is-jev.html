What is Jev?

Jev is a judge model. It does not chat with your customers — it grades the AI that does. You hand it a record of what happened plus the questions you care about, and it returns structured verdicts: yes or no, pick one, or a score.

How it works

  1. Give it the state — a support transcript, a tool-call log, a piece of agent output. Anything textual that records what happened.
  2. Ask questions in plain English — each question names its type (boolean, choice, or score) and the exact rule to apply.
  3. Get verdicts back — one answer per question, machine-readable, ready to gate a deploy, trigger a review, or feed a dashboard.

The three question types

TypeReturnsExample rule
booleantrue / falseTrue only if the agent stated the exact refund amount before asking to proceed.
choiceone labelClassify the ticket: billing, shipping, or account.
scorea numberRate the apology 1–5 for empathy and ownership.

Calling it

Jev runs as typesafe-ai/jev through the Vercel AI Gateway, using experimental_evaluate from the AI SDK. Set AI_GATEWAY_API_KEY in your environment — never paste the key into code.

import { experimental_evaluate } from 'ai';

const result = await experimental_evaluate({
  model: 'typesafe-ai/jev',
  state: 'Customer: I want a refund.\nAgent: I can refund $42.50 to your card. Shall I go ahead?',
  questions: {
    amount_disclosed: {
      type: 'boolean',
      instructions: 'True only if the agent stated the exact refund amount before asking to proceed.'
    }
  }
});
Jev is priced for always-on judging — about $0.042 per million input tokens through the gateway — so running it on every conversation costs less than the coffee you drink while reading the dashboard.
